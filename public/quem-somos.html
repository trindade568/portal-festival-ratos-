Sobre o projeto

Um festival fictício, um produto real

O desafio era criar um portal completo para um evento, com navegação clara, integração entre frontend e backend e execução local em servidor próprio.

O desafio

Desenvolver um portal com seis áreas obrigatórias — início, ingressos, line-up, local e estrutura, horários e produção — mantendo identidade visual consistente, responsividade e integração total com uma API própria.

Além da interface, era necessário persistir inscrições, validar dados no servidor, calcular a disponibilidade dos lotes em tempo real e simular um fluxo completo de pagamento até a emissão de um protocolo.

  • Seis páginas navegáveis e responsivas
  • API REST com dados reais do festival
  • Checkout simulado com protocolo
  • Acessibilidade por teclado e leitores de tela

A solução

Construímos o backend em Node.js puro, usando apenas o módulo http, sem dependências externas. Os dados do festival ficam em arquivos JSON e as inscrições são gravadas com escrita atômica.

No frontend, JavaScript vanilla renderiza os componentes a partir da API, com design system próprio, animações de entrada, favoritos na agenda, filtros de horários e mapa interativo em SVG.

Como foi feito

Da ideia ao servidor na porta 2000

Quatro etapas organizaram o desenvolvimento e garantiram a integração de ponta a ponta.

Pesquisa e arquitetura

Definimos a identidade, o mapa do site, os dados do festival e o contrato da API antes de escrever a interface.

Design system

Criamos tokens de cor, tipografia, componentes e estados de interação reutilizados em todas as páginas.

Frontend e backend

O servidor Node.js expõe os dados em JSON e o frontend renderiza tudo dinamicamente, com validação nos dois lados.

Testes e documentação

Validamos fluxos, mensagens de erro, responsividade e documentamos a execução local e os endpoints da API.
